# MS2LDA_Molecular_network_mapping
Mapping MS2LDA results on molecular networks created in GNPS

# CLI script:

MS2LDA_network_mappings_v1.0.py

# Input:

1. MGF file (created e.g., in mzmine) - Full feature list, containing all spectra used for molecular networking in GNPS
2. MS2LDA output files:
    a) ms2lda.bin
    b) ms2lda_viz.json (extracted .gz folder generated by MS2LDA)

# Output:

Depending on "mode", the output data frames have "long" and/or "wide" formats
1. motifs_long.csv
2. motifs_wide.csv

# Usage 
```bash
python MS2LDA_network_mappings_v1.0.py \
--mgf demo.mgf required=True \
--model ms2lda.bin required=True \
--viz ms2lda_viz.json required=True \
--outdir results_ms2lda_mapping required=True \
--threshold 0.002 type=float default=0.002 \
--mode both choices=["long", "wide", "both"] default="both"
```
## Example:

# Mapping on molecular network in Cytoscape:

After running the script and obtaining the CSV (required in **long** format for this type of mapping), the extracted motifs can be directly mapped on the existing molecular network in Cytoscape.

Note: Depending on the number of motifs extracted with MS2LDA, the number of columns added to the Cytoscape network can become quite large. For example: If you extracted 200 motifs with MS2LDA, mapping the long-format CSV will result in 200 additional columns.
Depending on your analysis, it may be more convenient to reduce the number of motifs (i.e., columns) for mapping on your network.
To do this, you can simply choose the motifs of interest in the long-format CSV, and create a new dataframe for mapping. 

Once you have chosen the motifs of interest, you can import the table into Cytoscape.
To do this, please follow these steps:
1. In Cytoscape, open your molecular network
2. Select "File --> Import --> Table from File"
3. A dialogue window will open automatically, in which you can specify the mapping key columns
4. Choose the right mapping column for your existing network in Cytoscape. Usually, this is the column "shared.name", which contains the feature IDs
5. Choose the right key column of the long-format CSV for mapping. This is the "feature_id" column
6. Make sure that the columns for the motifs are imported as floating points. Sometimes, Cytoscape imports these columns as strings. This can result in difficulties when you want to filter motifs using a threshold for the probability values, because Cytoscape interprets these columns as text, not as numbers
7. Click on "Ok". The motifs will now be mapped to the network, using the feature IDs as key column
8. You can now filter the motifs for a probability threshold of your choice. You can also use node shapes, outlines, fill colors, and any other styles of your choice to visualize the motif distribution on your network in Cytoscape. To do this, click on the "Style" tab on the right.
